延伸練習：查詢特定檔案的歷史

完成 main、HEAD 與歷史後，回到 history-demo。以下指令只讀取紀錄，並以第二章範例的三筆提交為起點；如果已完成自己做的 news.txt，最新提交會不同，但查詢方式不變。

bash
git log --oneline -- index.txt
git show HEAD:contact.txt
git log --oneline --all --graph --decorate

第一行列出影響 index.txt 的提交；第二行顯示目前版本的 contact.txt；第三行列出各個本地參照可到達的歷史。-- 用來把路徑與其他參數分開。

圖形介面的歷史檢視也會顯示提交、分支與差異；不同工具按鈕名稱可能不同，但概念一樣。只想查看紀錄時不必切換版本；若要在完整的舊版本中操作，參考查看過去版本。
