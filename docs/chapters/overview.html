Git 學習筆記

從第一筆 commit，到跟同學一起完成專案。這份教材以「先看圖解 → 跟著操作 → 自己完成任務」安排學習順序。

進入 SVG 互動圖解教室 · 教師課程安排 · 練習與測驗

開始之前

先完成 環境安裝與設定：準備 Git、編輯器與終端機，設定提交用的姓名與電子郵件。Windows 練習請使用 Git Bash。

操作前先確認三件事：在哪個資料夾？在哪個分支？這一步會改變什麼？ 用 pwd、git branch --show-current、git status 檢查。

第一階段｜建立版本

目標：自己建立記錄點，能試做新功能，也能保留原本可用的版本。

章節學習內容完成後你能做什麼？
01工作區與暫存區用 add 與 commit 保存正確的檔案版本
02main、HEAD 與歷史看懂目前分支與各筆 commit 的關係
03分支與合併在功能分支開發，完成後整合回 main
04忽略不需要追蹤的檔案用 .gitignore 排除暫存檔，理解已追蹤檔案的差別

階段任務： 建立一個小專案，在獨立分支新增關於我們頁面，提交並合併回 main。能說出工作區、暫存區與 commit 的差別，就可以繼續。

第二階段｜一起開發

目標：與同學分享成果，分工處理任務，檢查後才整合到共同版本。

先閱讀 GitHub 基本操作，準備帳號、clone 與登入方式。需要設定時，查閱 SSH 或 憑證。

章節學習內容完成後你能做什麼？
05GitHub 共同開發兩人各開分支，用 PR 檢查並合併成果
06用 Fork 交作業沒有老師專案的寫入權限，也能提出修改
07worktree：多任務工作保留未完成的功能，在另一個資料夾修 bug
08AI 開發的 Git 節奏小步修改、閱讀差異、驗證後提交，再用 PR 整合

階段任務： 兩人完成班級介紹，各自送 PR、互相檢查、合併後更新本地 main。再模擬一次 AI 修改失敗，說明你如何保留起點與處理錯誤。

第三階段｜復原與整理

目標：分清楚修改還沒提交、已暫存與已提交的情況，再選對復原方法。這一階段在主線練習完成後閱讀。

章節學習內容完成後你能做什麼？
09還原檔案與取消暫存分辨 restore、取消暫存與已提交版本的復原
10reset 的三種模式比較 soft、mixed、hard 改變哪些區域
11整理最後一筆提交在尚未分享的提交上練習 amend

階段任務： 在獨立練習專案中製造三種修改狀態，先預測結果，再操作驗證。不要把共享 main 當作修改歷史的練習場。
