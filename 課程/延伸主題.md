# 跨領域延伸主題

本頁供教師選用，不列入 Git 主線。工具介面與功能可能變動，課前請依實際版本準備；不把特定產品的功能視為永久規格。

## 環境與工具

- Git、編輯器、GitHub Desktop 與 GitHub CLI：依課堂需要選用。
- Python 虛擬環境：venv、Miniconda。
- Linux 基本檔案與路徑操作、樹莓派環境設定。
- GitHub 連線：區分 HTTPS 憑證、SSH 帳號金鑰與部署金鑰。

## 善用 AI 的練習

可選擇學校允許的工具，練習需求描述、摘要、比較與查證，不需要學生同時註冊所有服務。

1. 提供可公開的資料，請 AI 摘要並列出來源；不要上傳帳密與個人資料。
2. 實際打開來源核對，區分資料支持的結論與推測。
3. 用自己能說明的標準檢查結果，修正錯字、日期與遺漏。
4. 程式修改搭配 Git：讀 diff、實際驗證後提交。

## 文案與跨領域題材

- Markdown 排版、資料轉表格。
- 運動與環保、旅遊減碳。
- 高雄碼頭發展史、臺灣近代史。
- 臺灣北中南旅遊景點與 Python 基礎。

歷史、景點與減碳數字需要資料來源；引用圖片也要確認來源與使用範圍。

## 台中旅遊減碳提示詞範例

請創作一份五頁電子書，每頁有標題，正文 50 字以內，提供兩個版本。主題是台中旅遊減碳，內容適合學生閱讀；資料不足時請標示待查證，不自行編造數據。

接著可逐輪要求：每頁擴充到 100 字、加入趣味情境、把行程轉為表格、提出兩個封面構圖。每輪先確認資料與文字，再進行下一步；封面不必包含精確地理資訊。
