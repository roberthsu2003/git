# 延伸練習：閱讀差異與選擇提交內容

完成[工作區與暫存區](./README.md)後，可以用這兩個練習更仔細地觀察 diff。以下延續第一章的 `git-first`；先確認它的工作區乾淨。

## 只提交其中一個檔案

```bash
printf 'News\n' > news.txt
printf 'Notes\n' > notes.txt
git status --short
git add news.txt
git diff --staged
git commit -m "新增消息"
git status --short
```

`news.txt` 已提交，`notes.txt` 仍是未追蹤檔案。`git diff` 預設不顯示未追蹤檔案的內容；使用 `cat notes.txt` 閱讀它，再決定是否加入。

## 比較已暫存與未暫存的差異

```bash
printf 'First line\n' >> index.txt
git add index.txt
printf 'Second line\n' >> index.txt
git diff
git diff --staged
```

`git diff` 顯示暫存後加入的 `Second line`；`git diff --staged` 顯示自上一筆提交以來、準備放進下次提交的 `First line`。差異中 `+` 表示新增的行，`-` 表示移除的行；開頭的 `@@` 描述位置範圍。

練習完後，保留兩行修改並一併提交：

```bash
git add index.txt notes.txt
git diff --staged
git commit -m "補充首頁與筆記"
git status --short
```

若想取消暫存或丟棄指定修改，先閱讀[還原檔案與取消暫存](../回復被刪除的檔案或被編輯的內容/README.md)。
